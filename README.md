# Beekeeper Releases

Public, source-free Sparkle updates for the Beekeeper macOS app.

- `appcast.xml` is the signed Sparkle update feed.
- GitHub Releases contain `Beekeeper.zip` and a provenance manifest.
- Release tags use `beekeeper-v<version>`.
- The matching tag in the private source repository identifies the exact source
  commit used to build each archive.

This repository never contains Beekeeper source code or the Sparkle private
signing key. Published versions are immutable.
